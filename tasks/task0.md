Этап 0. Инспектор состояния (CLI)

Бизнес‑ценность: Операционный персонал может быстро оценить текущее состояние сервера без дополнительных инструментов.

Функциональные требования:

При запуске программа однократно собирает следующие метрики:

Загрузка CPU (в процентах) за последнюю секунду.

Использование памяти (в процентах, а также used/total в МБ).

Использование дискового пространства для корневой файловой системы (в процентах и used/total в ГБ).

Выводит результат в консоль в виде таблицы (можно использовать fmt.Printf).

Код реализован в одном файле main.go, без внешних зависимостей, кроме стандартной библиотеки и golang.org/x/sys/unix.

Программа завершается с кодом 0 при успехе, и с ненулевым кодом при ошибке (например, недоступность /proc).
Нефункциональные требования:

Время выполнения < 2 секунд.

Работает на Linux (включая WSL2).
Критерии приёмки:

Запуск go run main.go выводит таблицу с метриками.

Значения соответствуют данным из системных утилит (например, top, free -h, df -h).

Код проходит проверку go vet и golangci-lint (без критических ошибок).
