# Server Watch

HTTP-сервис для мониторинга системных метрик Linux.

На этапе 1 в проект добавлены:

* HTTP-сервер;
* endpoint для получения текущих метрик;
* endpoint health-check;
* базовая маршрутизация запросов;
* подготовка к дальнейшему расширению API.

---

## HTTP API

Основные endpoints:

```text
GET  /metrics
GET  /health
```
/metrics
Возвращает текущие системные метрики.

/health
Проверяет состояние сервиса.
# Запуск
Локальный запуск:
```bash
make run
```
# Проверка

Проверка кода:
```bash
make check
```
# Тесты:
```bash
make test
```
