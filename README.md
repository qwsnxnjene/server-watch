# Server Watch

Базовый скрипт для сбора системных метрик Linux.

На этапе 0 в проект добавлены:

* сбор CPU, RAM и Disk metrics;
* вывод метрик в консоль;
---

## Что делает скрипт

Скрипт получает текущие значения системных метрик и отображает их в читаемом виде в консоли.

На этом этапе:

* нет HTTP API;
* нет хранения истории измерений;
* нет внешних интеграций.

---

# Запуск

Локальный запуск:

```bash
make run
```
# Проверка

Быстрая проверка кода:
```bash
make check
```
# Запуск тестов:
```bash
make test
```
# Ограничения этапа
На этом этапе проект сознательно не решает:
* HTTP API;
* хранение метрик;
